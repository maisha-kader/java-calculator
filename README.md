# **Java Calculator**

## About the Project:

It is a calculator application developed using Java and IntelliJ IDEA.

The project was created to practice Java programming and strengthen my understanding of programming fundamentals and problem-solving.

## Programming Language:

Java

## Development Environment:

IntelliJ IDEA

## Features:

- Performs calculator operations.
- Accepts user input.
- Displays calculator results.
- Includes an easter egg (or two)

- Developing problem-solving skills.
